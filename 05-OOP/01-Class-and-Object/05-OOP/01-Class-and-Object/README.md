# C++ OOP - Class and Object

## Topic
Introduction to Class and Object in C++.

## Concepts Learned
1. Creating a class.
2. Creating multiple objects.
3. Declaring data members.
4. Accessing class members using objects.
5. Storing student information.

## Programming Language
C++

## Example
Created three student objects:
- Dani
- Dip
- A common man

Each object contains:
- Name
- Age
- CGPA

## Learning Goal
Understanding the basic concepts of Object-Oriented Programming (OOP).
